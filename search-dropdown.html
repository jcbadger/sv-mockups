About Search

Search lets you find content in this ShareVault in different ways. Choose Files or Folders to set what you're searching for, then optionally turn on AI Search to search by concept rather than by exact words.

Files

Searches for individual files by filename, file index number, file contents, file description, or file ID. Use this when you're looking for specific files or want search results at the file level based on matching the keywords you've entered.

Folders

Searches for folders by folder name, folder index number, or folder description showing matching folders. Use this when you want to quickly navigate to a particular folder or subfolder, ignoring the files themselves.

AI Search

Searches by concept and intent rather than by exact text matches. Describe what you're looking for in your own words and the search will find relevant results even when they don't match specific keywords. Use this when you're unsure of the exact wording, when you're exploring a topic, or when relevant material may be phrased many different ways. Works with either Files or Folders. Give it a try — AI Search suggests ideas for what to look for in this ShareVault.

Selecting a folder

Whether you're in Files mode or Folders mode, selecting a folder from the suggestions checks the folder in the Index to the left, filtering the file list to that folder.
